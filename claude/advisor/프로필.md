# 운용 프로필

> **상태: 미작성.** 어드바이저는 이 문서를 P1의 첫 입력으로 읽는다.
> 비어 있는 항목은 추정하지 않고 `결측`으로 처리하며, 결측이 있는 상태의 판정은
> 기록부에 `프로필결측`으로 표시된다. 채우기 전까지는 어떤 어드바이저도 P3(투자)로 가지 않는다.

## 공통

| 항목 | 값 |
|---|---|
| 투자 지평 (은퇴 목표 시점 등) | |
| 원화 기준 최대 감내 손실 (%) | |
| 정기 납입 여력 (월, 원) | |
| 비상금 (투자자산 밖 현금) | |
| 이 시스템에서 제외할 자산 (부동산·퇴직연금 등) | |

## PEN — 연금저축

| 항목 | 값 |
|---|---|
| 개설 여부 / 금융사 | |
| 현재 평가액 | |
| 현재 보유 상품 (상품명·비중) | |
| 올해 납입액 / 남은 납입 여력 | |
| 이 계좌의 역할 (본인 정의) | |

## ISA

| 항목 | 값 |
|---|---|
| 개설 여부 / 유형 / 금융사 | |
| 개설일 → 만기일 | |
| 현재 평가액 | |
| 현재 보유 상품 (상품명·비중) | |
| 올해 납입액 / 남은 납입 여력 | |
| 만기 후 계획 (연금계좌 이전 / 해지) | |

## GLB — 해외 일반계좌

| 항목 | 값 |
|---|---|
| 금융사 | |
| 현재 평가액 | |
| 현재 보유 종목 (티커·수량·평단) | |
| 올해 실현 손익 (양도세 기본공제 소진 여부) | |
| 위성 종목 수 상한 (기본 5) | |

## 규율 설정

| 항목 | 값 (기본값) |
|---|---|
| 정기 실행일 | PEN·ISA: 분기 정기조정일 / GLB: 월 1회 |
| 위성 종목 최대 개수 | 5 |
| 단일 종목 최대 비중 (전체 자산 대비) | |
| 재량 매매 허용 여부 | 허용하되 기록부에 `재량`으로 표기 |
