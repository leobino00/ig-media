## 이어서 하는 법

`상태.tar.gz`를 스크래치패드에 풀면 다음 파일이 나온다.

| 파일 | 내용 |
|---|---|
| `audit-raw-findings.json` | 8관점 탐색 원본 (관점별 findings) |
| `audit-verdicts.json` | 완료된 검증 판정 + 중복 그룹 |
| `audit-merged.json` | 병합 목록 118건 + 미검증 32건 |
