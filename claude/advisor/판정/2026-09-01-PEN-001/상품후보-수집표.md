## 1. 후보 목록 만들기

거래 증권사 앱/HTS에서 **연금저축 계좌로 로그인한 상태**로 조회한다.
일반계좌 화면에서 보이는 상품이 연금저축에서 안 되는 경우가 있다.

- 연금저축 계좌 → ETF 검색 → 확정한 자산군의 기초지수로 검색
- **같은 지수를 따르는 상품을 전부 담는다.** 브랜드로 미리 거르지 않는다
- 보통 3~5개가 나온다

---

## 2. 후보별 수집 항목

**같은 지수를 따르는 상품끼리는 TER·추적오차·유동성으로만 비교한다**(스킬 규정).
과거 수익률 랭킹, 운용사 브랜드, 순자산 1위 여부로 고르지 않는다.

| # | 항목 | 어디서 | 왜 필요한가 |
|---|---|---|---|
| 1 | **상품명 / 종목코드** | 증권사 앱 | |
| 2 | **기초지수 (정확한 명칭)** | 상품 설명 | 이름이 비슷해도 지수가 다른 경우가 있다 |
| 3 | **총보수(TER) %** | 운용사 상품 페이지 | **26년 지평에서 가장 확실하게 작동하는 변수** |
| 4 | **실부담비용률 %** (있으면) | 운용사 / 금투협 | TER에 기타비용을 더한 값. TER보다 실제에 가깝다 |
| 5 | **순자산 (억원)** | 네이버금융 / KRX | 너무 작으면 상장폐지 위험 |
| 6 | **최근 3개월 일평균 거래대금** | 네이버금융 | 매수·매도 시 호가 스프레드 |
| 7 | **추적오차 / 괴리율** | 운용사 월간 리포트 | 지수를 얼마나 잘 따라가는가 |
| 8 | **분배금 지급 여부·주기** | 상품 설명서 | 연금계좌는 과세이연이라 분배해도 손해가 아니다. 재투자형이면 관리가 간단 |
| 9 | **환헤지 여부 (H / 언헤지)** | 상품명에 (H) 표시 | **원화 노출 0.08% 문제와 직결** |
| 10 | **연금저축 계좌 매수 가능 여부** | 증권사 앱에서 실제 검색 | 파생형·레버리지·인버스는 매수 불가 |

## 4. 최소 조건 — 이것만 있어도 판정 가능

전부 못 채워도 된다. **3·5·9·10** 네 개만 있으면 상품 선택을 확정할 수 있다.

| 우선순위 | 항목 | 없으면 |
|---|---|---|
| **필수** | 총보수(TER) | 상품 비교 자체가 불가 |
| **필수** | 연금저축 매수 가능 여부 | 못 사는 상품을 고를 수 있다 |
| **필수** | 환헤지 여부 | 자산군 판정 결과와 어긋날 수 있다 |
| 강력 권장 | 순자산 | 상장폐지 위험 미확인 |
| 있으면 좋음 | 나머지 | 확신도만 올라간다 |

---

## 5. 이 표가 채워지면

1. 어드바이저가 P1 결측 3건(TER·추적오차·분배)을 해소하고 **확신도를 `하` → `중`/`상`으로 올린다**
2. 상품을 확정해 P3 사전등록(목표비중·진입방식·무효화조건·재검토일)을 작성한다
3. 기록부 `실행` 열을 채운다

**후보가 하나뿐이어도 표를 채운다.** 비교 대상이 없다는 사실 자체가 기록이다.
