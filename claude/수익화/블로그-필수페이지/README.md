# 티스토리 필수 페이지 3종 + 광고 신청 순서

애드센스 심사에서 가장 자주 발목을 잡는 것이 "사이트 골격"(소개·연락·정책 페이지)이다. 글 수보다 먼저 이걸 채운다.

## 붙여넣는 법 (5분)

1. 티스토리 관리 → **콘텐츠 → 페이지 → 페이지 쓰기**
2. 제목을 아래 표대로 적고, 에디터 우상단 **기본 모드 → HTML** 로 바꾼 뒤 파일 내용을 그대로 붙여넣기
3. **공개** 발행. URL 슬러그는 표의 값으로
4. 꾸미기 → **메뉴** 에 세 페이지를 추가 (상단 메뉴 노출이 심사에 유리)

| 파일 | 페이지 제목 | 슬러그 |
|---|---|---|
| `소개.html` | 소개 | `about` |
| `개인정보처리방침.html` | 개인정보처리방침 | `privacy` |
| `면책고지.html` | 투자 정보 면책고지 | `disclaimer` |

## 광고 신청 순서

| 순서 | 무엇 | 조건 | 걸리는 시간 | 어디서 |
|---|---|---|---|---|
| 1 | **카카오 애드핏** | 개설 30일 경과 + 최근 3개월 20편 | 1~7일 | adfit.kakao.com → 매체 등록 → 승인 후 티스토리 플러그인 "카카오 애드핏" 켜기 |
| 2 | **애드센스** | 위 3페이지 + 독창적 글 15~25편(편당 1,000자 이상) + 카테고리 정돈 | 2~6주 (2026년 심사 장기화) | adsense.google.com → 사이트 추가 → 티스토리 플러그인 "구글 애드센스"에 코드 |
| 3 | 승인 뒤 | 애드핏 위치를 사이드바 1개로 줄인다 (광고 밀도 감점 방지) | | |

### 애드센스 신청 전 체크

- [ ] 글 25편 (현재 12편 안팎 → 주 2편이면 6주)
- [ ] 편당 본문 1,000자 이상, 표·이미지 ALT 포함 (`tistory-auto-publish` 규칙대로)
- [ ] 빈 카테고리 없음 (`팔로업` 카테고리를 만들면 최소 3편 채운 뒤 노출)
- [ ] 페이지 3종 메뉴 노출
- [ ] 방문자 통계에서 검색 유입이 하루 10명 이상 (네이버·구글 서치콘솔 등록: 관리 → 플러그인 → 사이트 인증)
- [ ] 다른 블로그 글을 옮겨 온 것 없음
