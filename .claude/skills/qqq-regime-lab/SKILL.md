# QQQ 레짐 전환 실험실

`scripts/qqq_regime/` 을 돌려 **가상의 매매 규칙을 과거 실제 가격에 적용한 결과**를 낸다.
구현·데이터 출처·검증은 `scripts/qqq_regime/README.md`, 결과는 `scripts/qqq_regime/출력/보고서.md`.

## 경계

| 금지 | 이유 |
|---|---|
| 실제 계좌의 매수·매도·비중을 정하는 것 | 판정은 `claude/advisor/PROTOCOL.md` 5단계를 거쳐야 나온다. 이 실험실은 그 절차가 아니다 |
| `claude/advisor/` · `claude/판정기록부.md` 에 쓰는 것 | 판정ID가 없다 |
| **앞으로의 수익률을 말하는 것** | 이 실험은 과거 실현치다. 「연 X% 기대」는 여기서 나오지 않는다 |
| 최적 파라미터를 추천하는 것 | 표본내 1등이 표본외 7등이었다. 추천의 근거가 실험 자체에 의해 부정됐다 |

읽고 쓰는 곳은 `scripts/qqq_regime/` 안뿐이다.

## 절차

```bash
python3 scripts/qqq_regime/self_test.py            # 1. 시험 41건 — 깨지면 멈춘다

python3 scripts/qqq_regime/experiment.py           # 2a. 3상태 (TQQQ/SQQQ/현금)
python3 scripts/qqq_regime/report.py               #     → 출력/보고서.md

python3 scripts/qqq_regime/experiment_2state.py    # 2b. 2상태 (TQQQ/현금) + 2000년 확장
python3 scripts/qqq_regime/report_2state.py        #     → 출력/보고서-2상태.md
```

산출물이 최신이면 다시 돌리지 않고 해당 보고서를 읽어 답한다.

**질문에 맞는 보고서를 고른다.** 숏을 쓰는 이야기면 3상태, 아니면 2상태다.
2상태 쪽이 규칙 60개로 더 넓고 2000년 구간(닷컴·금융위기)까지 있으므로 기본은 2상태다.

### 2상태 결과를 인용할 때

**기간을 반드시 함께 말한다 — 답이 뒤집힌다.** 2010~2026만 보면 규칙 60개 중 **0개**가
TQQQ 바이앤홀드(+41.67%)를 이기지 못했고, 2000~2026으로 늘리면 바이앤홀드가
**CAGR −1.38%·MDD −99.97%** 로 소멸하고 규칙 중앙값은 **+12.30%** 다.
한쪽만 인용하면 정반대 인상을 준다.

## 규칙을 바꿔달라고 하면

1. `signals.py` 에 규칙을 **함수로** 추가하고 `build_grid()` 에 넣는다. 신호는 **기준주까지의
   데이터만** 쓴다 — `backtest.py` 가 t+1 주에 적용하므로 여기서 미래를 보면 이중으로 새는 게 아니라
   그대로 새어버린다.
2. `self_test.py` 에 그 규칙의 **경계값 시험**을 추가한다. 경계는 약한 쪽으로 센다.
3. 전수를 다시 돌린다. **새 규칙 하나만 돌려서 보고하지 않는다** — 비교 대상이 없으면 숫자가 의미를 잃는다.
4. 그리드가 커지면 `README.md` 의 규칙 표를 같이 고친다.

## 답할 때 지키는 것

| 규칙 | 내용 |
|---|---|
| **중앙값을 먼저 말한다** | 최고 규칙의 수익률을 머리기사로 쓰지 않는다. 쓸 때는 「35개 중 1등」을 함께 적는다 |
| **범위를 함께 말한다** | 규칙 선택에 따른 폭이 중앙값보다 크다. 폭을 빼면 숫자가 거짓말이 된다 |
| **벤치마크를 함께 말한다** | 같은 기간 QQQ·TQQQ 바이앤홀드 옆에 놓지 않은 수익률은 평가할 수 없다 |
| **낙폭을 함께 말한다** | 수익률만 말하면 −89% 구간이 사라진다 |
| **세금·환율이 빠졌다고 말한다** | 국내 계좌 기준 세후·원화 수익률은 보고서 숫자보다 낮다 |
| 기간을 밝힌다 | 레버리지 구간은 2010-02-19부터다 (TQQQ·SQQQ 실제 상장일) |

## 레버리지 합성을 요청받으면

**거절하지 말되, 오차를 먼저 보여준다.** QQQ 주간 등락률에 3을 곱하는 합성은 같은 기간
실제 TQQQ를 **연 +9.66%p 과대평가**한다 (README 「왜 실제 가격을 쓰는가」).
2010년 이전을 보고 싶으면 **레버리지를 빼고 1배로** 본다 — 보고서 「결과 4」가 그 방식이다.

## 이 실험실이 하지 않는 것

- 미래 수익률 예측
- 실제 주문·계좌 연동
- 일간·장중 신호 (주간 종가 전환만)
- QQQ 계열 외 종목
