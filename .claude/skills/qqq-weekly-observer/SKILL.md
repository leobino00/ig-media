# QQQ 주간 관측기

`scripts/qqq_weekly/` 프로그램을 돌려 QQQ 주간 종가의 **사실**을 낸다.
구현·계산 정의·한계는 `scripts/qqq_weekly/README.md` 에 있다. **이 스킬은 규칙만 정한다.**

## 경계 — 시작 전 반드시 읽는다

**이 스킬은 어드바이저 시스템과 섞이지 않게 만든 것이다.** 아래는 예외 없다.

| 금지 | 이유 |
|---|---|
| 매수·매도·비중·진입·청산을 말하는 것 | 판정은 `claude/advisor/PROTOCOL.md` 의 5단계(P1~P5)를 거쳐야 나온다. 이 스킬은 그 절차를 거치지 않는다 |
| `claude/판정기록부.md` 에 행을 쓰는 것 | 판정ID가 없다. 기록부는 판정만 들어간다 |
| `claude/advisor/` 아래 어느 파일이든 쓰는 것 | 특히 `월간판정/입력/` — 검증되지 않은 축이 10지표 판정에 끼어든다 |
| `advisor-*` · `nasdaq-*` 스킬을 이어서 호출하는 것 | 사용자가 그것을 요청했을 때만 그 스킬이 처음부터 자기 절차로 돈다 |
| 앞으로의 움직임을 말하는 것 | 관측은 지나간 값이다. 전망은 관측이 아니다 |

**쓰는 곳도 읽는 곳도 `scripts/qqq_weekly/` 안뿐이다.**

### 판정을 요청받으면

관측만 주고, 판정은 어느 스킬이 하는지 알려준 뒤 **거기서 멈춘다.**
관측값을 근거로 "그러니까 …" 를 붙이지 않는다. 한 문장이라도 붙이는 순간
**5단계를 건너뛴 판정**이 되고, 그것이 이 스킬을 만들어 분리한 이유를 없앤다.

> 예: 「지금 사도 되나」 → 전고점 대비 낙폭과 과거 같은 구간의 회복 소요 주를 **사실로** 보여 준다.
> 그다음 "계좌 판정은 `advisor-global`(해외 일반계좌) 또는 `advisor-coordinator`(계좌 간 배분)가
> 5단계로 한다" 고 알리고 끝낸다. 어느 쪽이 좋다고 말하지 않는다.

## 절차

```bash
python3 scripts/qqq_weekly/self_test.py                                 # 1. 시험 76건
python3 scripts/qqq_weekly/observe.py                                   # 2. 관측 산출
python3 scripts/qqq_weekly/lint_no_judgment.py \
        scripts/qqq_weekly/출력/qqq-weekly-latest.md                    # 3. 어휘 검사
```

1. **시험이 깨지면 산출하지 않는다.** 계산 정의가 깨진 채 나온 숫자는 관측이 아니다.
2. 산출물은 `scripts/qqq_weekly/출력/` 에 있다 (`latest.md` · `latest.json` · 기준일 스냅샷).
3. **어휘 검사가 걸리면 그 문장을 고친다.** 예외를 두지 않는다.
4. 사용자에게 답할 때는 `latest.md` 의 값을 **그대로 인용한다.** 다시 계산해 말하지 않는다 —
   말로 한 계산은 `CALC_VERSION` 이 붙지 않아 나중에 어느 정의로 낸 값인지 알 수 없다.

산출물이 이미 최신(`as_of` 가 입력 마지막 주와 같다)이면 다시 돌리지 않고 읽어서 답한다.

## 답할 때 지키는 것

| 규칙 | 내용 |
|---|---|
| 기준일을 먼저 말한다 | 모든 값은 `as_of` 기준이다. 기준일 없는 숫자는 나중에 대조할 수 없다 |
| 결측은 결측이라고 말한다 | `missing[]` 에 있는 값을 추정해 채우지 않는다. **0으로 대체하지 않는다** |
| 한계를 함께 싣는다 | 특히 **배당 반영 여부가 미확인**이라는 것. 누적 등락률·CAGR을 인용할 때는 반드시 붙인다 |
| 「전 구간」의 범위를 밝힌다 | 2007-01-05 시작이다. 최대 낙폭 −51.67%는 **상장 이래 최대가 아니다**(2000~2002년이 빠져 있다) |
| 낙폭은 주간 종가 기준이다 | 일간·일중 기준 실제 낙폭보다 얕다 |
| 연중 연도를 연간처럼 쓰지 않는다 | 마지막 해에는 `partial_reason` 이 붙는다 |

## 데이터를 갱신할 때

1. **같은 출처에서** 받은 새 주를 `data/qqq_weekly.csv` **끝에 덧붙인다.** 과거 행은 고치지 않는다.
2. 출처가 바뀌면 `data/qqq_weekly.출처.md` 에 바뀐 날짜와 사유를 적는다.
3. 위 절차 1~3을 다시 돌린다. 스냅샷은 **덮어쓰지 않는다** — 기준일마다 파일이 하나씩 쌓인다.
4. 계산 정의를 바꿨으면 `calc.CALC_VERSION` 을 올린다. **과거 스냅샷은 다시 계산하지 않는다.**

## 이 스킬이 하지 않는 것

- 실시간 가격 조회 (네트워크를 쓰지 않는다)
- QQQ 외 다른 심볼
- 환율·원화 환산
- 백테스트·전략 성과 비교 — 전략의 우열을 말하는 순간 판정이다
