# 해외주식 어드바이저 (GLB)

## 시작 전 반드시 읽는다

1. `claude/advisor/PROTOCOL.md` — 5단계 공용 규칙. **이 스킬은 P1과 P3만 규정한다. P2·P4·P5는 프로토콜 그대로 따르고 여기에 다시 쓰지 않는다.**
2. `claude/advisor/계좌-제약.md` — GLB 절
3. `claude/advisor/프로필.md` — GLB 절

계좌코드 `GLB`. 판정ID는 `YYYY-MM-DD-GLB-NNN`.

## 이 계좌의 성격 — 먼저 이해할 것

**개별 해외종목을 담을 수 있는 유일한 계좌이고, 매도 자체에 세금 비용이 명시적으로 붙는 유일한 계좌다.**

- 개별종목은 지수보다 **틀릴 여지가 크고 틀렸을 때 회복이 보장되지 않는다.** 그래서 이 계좌에서는 P2를 더 엄격하게 적용한다(아래 추가 규칙).
- 매도에 양도세가 붙으므로 회전율의 대가가 눈에 보인다. 연말 손익통산이 판단에 들어온다.
- 배당에 현지 원천징수가 발생하므로 **고배당 자산을 여기 두는 것은 자산배치상 불리하다.** 고배당은 PEN·ISA로 넘긴다.

## P1 — 이 계좌의 조사 입력

| 항목 | 왜 필요한가 |
|---|---|
| 위성 슬롯 잔여 (기본 상한 5) | 슬롯이 없으면 신규 매수가 아니라 **교체 판정**이다 |
| 기존 보유 종목과의 섹터·기초 노출 중복 | 종목 5개가 사실상 같은 베팅인 경우가 흔하다 |
| 올해 실현손익 / 양도세 기본공제 잔여 | 매도 판정과 연말 실행 시점에 직접 영향 |
| 다음 기준일 (상품 유형별) | **무효화 조건의 기준 날짜.** 필수. 개별주식은 실적 발표일, CEF는 분배금 공시일 — P2 절의 표 참조 |
| 현재가 / 52주 밴드 / 시가총액 | |
| **총보수 및 그 구성** | 펀드형 상품(CEF·ETF)일 때 필수. **레버리지를 쓰는 상품은 이자비용이 총보수의 대부분일 수 있고, 그것은 운용사가 통제하지 않는 금리 연동 비용이다** |
| 밸류에이션 (배수 + 비교 대상) | 배수만 적고 비교 대상이 없으면 결측 처리. **CEF는 NAV 대비 할인/할증률이 이 자리에 온다 — 동종 평균이라는 비교 대상 없이는 마찬가지로 결측이다** |
| 강세 논거 3~6 / 약세 논거 3~6 (**출처 표기 필수**) | P2 문항 3의 재료 |
| 환율 및 원화 환산 기준 | 버는 것은 원화다 |

### 슬롯이 없으면 신규가 아니라 교체다

위성 슬롯 상한(기본 5)이 찼는데 새 종목을 담고 싶다면, 그것은 **신규 매수 판정이 아니라 교체 판정**이다.
이 경우 기존 보유 중 하나를 P5로 소집해 사후평가를 먼저 끝내고, **두 종목을 같은 기준으로 비교한 뒤** 판정한다.
새 종목만 조사해서 담고 기존 종목은 그대로 두는 방식은 **종목 수만 늘어나는 가장 흔한 경로다.**

### 확신도

| 확신도 | 기준 |
|---|---|
| 상 | 필수 입력 8개 결측 0개, 강세·약세 논거 각 3개 이상이 **출처와 함께** 확보 |
| 중 | 결측 1개 이하 |
| 하 | 결측 2개 이상, 또는 약세 논거를 출처와 함께 찾지 못함 |

**약세 논거를 출처와 함께 찾지 못했으면 확신도는 무조건 `하`다.** 반대편이 안 보이는 것은 반대편이 없다는 뜻이 아니라 덜 찾아봤다는 뜻이다.

## P2 추가 규칙 — 개별종목에만 적용

프로토콜의 4문항에 더해:

- **무효화 조건 중 최소 1개는 아래 표의 기준일을 날짜로 삼아야 한다.** 날짜가 정해지지 않은 무효화 조건만 있으면 문항 4는 기각 실패로 처리한다.

  | 상품 유형 | 기준일 | 이유 |
  |---|---|---|
  | 개별주식 | **다음 실적 발표일** | 가장 빨리, 가장 확실하게 판정이 갈리는 지점 |
  | **폐쇄형펀드(CEF)** | **다음 분배금 공시일** (+ 반기·연차 보고서 공개일) | 분배금 삭감이 CEF에서 가장 빠른 이상 신호다 |
  | ETF·인덱스 상품 | **다음 정기 리밸런싱일** 또는 지수 구성 변경 공시일 | |
  | 위 어디에도 없는 상품 | 사용자와 합의한 **고정 날짜** (최소 분기 1회) | 날짜 없는 무효화 조건을 허용하지 않기 위한 최후 규정 |

  > 이 표는 `2026-09-01-GLB-001`(HYT 조사)에서 나왔다. 원래 규칙이 "실적 발표일"만 인정해
  > **실적 발표가 없는 CEF는 어떤 무효화 조건을 써도 문항 4를 통과할 수 없었다.**
  > 규칙이 판정을 불가능하게 만들면 그 규칙이 틀린 것이다.
- **문항 3(가장 강한 반대편 논거)에서 "찾지 못함"은 개별종목에서는 기각 실패로 처리한다.** 지수와 달리 개별종목에는 반대편이 반드시 존재한다.

## P3 — 이 계좌의 실행 규칙

1. **정기 실행일은 월 1회.** 그 외의 날 매매는 재량으로 기록한다.
2. 위성 종목 수 상한을 넘기지 않는다. 넘기려면 교체 판정을 거친다.
3. 사전등록 4항목을 적기 전에 주문하지 않는다.
4. **재검토일 기본값은 다음 실적 발표일.**
5. **12월에는 전 보유 종목을 P5로 일괄 소집한다.** 양도세 기본공제 잔여와 실현손익을 대조하는 시점이다. 다만 **세금 때문에 판정을 뒤집지 않는다** — 판정은 판정대로 하고, 세금은 실행 시점만 조정한다.
6. 급락·과열 국면 대응은 `nasdaq-event-trigger` 규칙을 따른다. 이 스킬이 따로 임계치를 만들지 않는다.

## P4에서 특히 주의할 것

개별종목 글은 이 시스템에서 **가장 위험한 공개물**이다. 프로토콜 P4에 더해:

- 보유 중인 종목 글에는 **보유 사실과 평단 여부를 명시한다.**
- P2 문항 3의 반대편 논거를 **원문 그대로** 싣는다. 요약해서 약하게 만들지 않는다.
- 무효화 조건을 날짜와 함께 싣는다. **이것이 있으면 나중에 정정할 수 있고, 없으면 정정할 방법이 없다.**
- 원고 작성은 `naver-stock-blog`, 발행은 `tistory-auto-publish`에 넘긴다.
