# qqq-weekly-observer

QQQ 주간 종가 시계열에서 **사실만** 뽑아 `출력/qqq-weekly-latest.{md,json}` 으로 낸다.

> ## 경계 — 이것부터 읽는다
>
> **이 프로그램은 어드바이저 시스템과 무관하다.** 섞지 않기 위해 만든 것이다.
>
> | 하지 않는 것 | 이유 |
> |---|---|
> | 매수·매도·비중 판정 | 판정은 `claude/advisor/PROTOCOL.md` 의 5단계(P1~P5)를 거쳐야 나온다. 이 프로그램은 그 절차를 거치지 않는다 |
> | `claude/판정기록부.md` 기록 | 판정ID가 없다. 기록부는 판정만 들어간다 |
> | `claude/advisor/월간판정/입력/` 에 쓰기 | 그 디렉터리는 월간 판정의 입력이다. 여기 출력이 섞이면 10지표 판정에 검증되지 않은 축이 하나 끼어든다 |
> | 기존 스킬 호출·참조 | `advisor-*` · `nasdaq-*` 과 코드·데이터·출력을 공유하지 않는다 |
> | 네트워크 접근 | 입력은 `data/qqq_weekly.csv` 하나뿐이다 |
>
> **이 저장소의 기존 파일은 한 줄도 고치지 않았다.** 전부 `scripts/qqq_weekly/` 와
> `.claude/skills/qqq-weekly-observer/` 안에 있다.
>
> 관측을 판정으로 쓰고 싶어지면, **그때 어드바이저를 불러 P1 입력으로 인용한다.**
> 이 프로그램이 판정으로 넘어가지 않는다.

## 파일

| 파일 | 역할 |
|---|---|
| `calc.py` | 계산 정의. `CALC_VERSION` 이 출력 `version` 이 된다. 수집도 출력도 없다 |
| `load.py` | CSV 파서·검증. 이상은 고치지 않고 기록하거나 멈춘다 |
| `observe.py` | 관측 산출 (`md` + `json` + 기준일 스냅샷) |
| `lint_no_judgment.py` | 「관측」 절 판단 어휘 검사 |
| `self_test.py` | 단위 시험 76건. 네트워크·저장소 데이터 불필요 |
| `data/qqq_weekly.csv` | 입력 (1028주) |
| `data/qqq_weekly.출처.md` | 출처 카드. **배당 반영 여부가 결측이라는 사실이 여기 있다** |
| `출력/` | 산출물. `qqq-weekly-latest.{md,json}` + `qqq-weekly-YYYY-MM-DD.json` |

## 실행

```bash
python3 scripts/qqq_weekly/self_test.py                                     # 시험 76건
python3 scripts/qqq_weekly/observe.py                                       # 관측 산출
python3 scripts/qqq_weekly/lint_no_judgment.py \
        scripts/qqq_weekly/출력/qqq-weekly-latest.md                        # 어휘 검사

python3 scripts/qqq_weekly/observe.py --csv PATH --out DIR --no-snapshot    # 입출력 바꾸기
```

자동 실행을 걸지 않았다. 기존 `.github/workflows/macro-fetch.yml` 에 단계를 붙이면
**같은 커밋 사이클에 섞이므로** 그렇게 하지 않았다. 필요해지면 별도 워크플로를 만든다.

## 계산 정의 (`calc.py` · v0.1)

주간 종가만 쓴다. 전부 달러 기준이다.

| 항목 | 정의 |
|---|---|
| 주간 등락률 | `close(t)/close(t−1) − 1`, % |
| `sma_Nw` | 최근 N주 종가 단순평균. 표본 < N 이면 결측 |
| `above_sma_Nw` | `close(t) > sma_Nw` — **strict.** 같으면 위가 아니다 |
| `ret_Nw_pct` | `close(t)/close(t−N) − 1`, % |
| `vol_Nw_annualized_pct` | 최근 N개 주간 등락률의 **표본표준편차(n−1)** × √52, % |
| `from_all_time_high_pct` | `close(t)/max(close, 전 구간) − 1`, % |
| `max_drawdown_pct` | 전 구간 최대 낙폭 (고점·저점 날짜 함께) |
| 낙폭 구간 | 「직전 사상 최고 → 최저 종가 → 최고 회복」 1건. 임계치 −10 / −20 / −30% |
| `up_week_ratio_pct` | 주간 등락률 **> 0** 인 주의 비율 — **strict.** 0.00%는 상승 주가 아니다 |
| 백분위 | 선형보간 |
| 연도별 등락률 | 그 해 마지막 관측 종가 ÷ 직전 해 마지막 관측 종가 − 1 |
| CAGR | `(마지막/처음)^(365.25/일수) − 1`, % |

**경계값은 약한 쪽으로 센다.** `self_test.py` 가 `close == sma` · `등락률 == 0` ·
`낙폭 == −10.00%` · `낙폭 == −20.00%` 네 경계를 못박는다.

> **부동소수 허용치 `DD_EPS = 1e-9`.** `90/100 − 1` 은 이진부동소수에서 `−9.999999999999998%`
> 로 나온다. 허용치가 없으면 **정확히 −10% 인 낙폭이 −10% 임계치에서 빠진다.**
> 허용치는 표시 자리수(0.01%p)보다 일곱 자리 작으므로 −9.99%를 −10%로 끌어올리지 않는다.
> `DD_EPS = 0` 으로 두면 시험 2건이 깨진다(확인함).

정의를 바꾸면 `CALC_VERSION` 을 올린다. 과거 스냅샷은 다시 계산하지 않는다 —
어느 시점부터 정의가 달라졌는지 출력 파일만 보고 알 수 있어야 한다.

## 결측 규칙

추정하지 않는다. 채우지 않는다.

- 값은 `null`, 이름은 `missing[]`, 사유는 `missing_detail{}` 에 남긴다.
- 표본이 모자란 지표만 결측이고 나머지는 낸다 (예: 20주치 입력이면 52주 지표만 결측).
- **결측을 0으로 대체하지 않는다.** 0은 「모른다」가 아니라 「없다」는 주장이다.
- 결측 주가 의심되면(간격 10일 초과) `input.gaps` 에 적고 **보간하지 않는다.**
- 치명적 이상(파일 없음·열 누락·날짜 중복·역순·종가 0 이하)은 **멈춘다**(종료코드 2).
  시계열을 조용히 고치고 계산을 계속하는 것보다 멈추는 편이 낫다.

## 산출물

```
scripts/qqq_weekly/출력/qqq-weekly-latest.md        사람용
scripts/qqq_weekly/출력/qqq-weekly-latest.json      기계용
scripts/qqq_weekly/출력/qqq-weekly-YYYY-MM-DD.json  기준일 스냅샷 (덮어쓰지 않는다)
```

json 최상위 키는 고정이다: `as_of` `generated_at` `symbol` `boundary` `series` `input`
`span` `latest` `trend` `returns` `volatility` `drawdown` `distribution` `history`
`missing` `missing_detail` `caveats` `version`. `self_test.py` 가 이 집합을 검사한다.

md 는 `## 경계` · `## 관측` · `## 입력 점검` · `## 결측` · `## 한계` 다섯 절이다.
**어휘 검사는 `## 관측` 절만 본다** — 「경계」·「한계」 절에서는 금지 어휘를
부정형(「판정하지 않는다」)으로 쓰는 것이 정상이기 때문이다.

## 이 입력의 한계 (매 산출물 꼬리에 그대로 실린다)

| 한계 | 내용 |
|---|---|
| **배당** | 반영 여부 **미확인**. 2007-01-05 값(43.85)이 당시 미수정 종가와 같다 — 미수정일 가능성이 높지만 추론이다. 미수정이면 누적 등락률·CAGR이 실제 총수익보다 낮다 |
| **주간 종가** | 주중 고가·저가를 모른다. 낙폭이 일간 기준보다 얕게 측정된다 |
| **단일 출처** | 원자료와 대조한 기록이 없다 |
| **통화** | 달러 기준. 환율을 반영하지 않는다 |
| **구간** | 2007-01-05 시작. 2000~2002년 낙폭은 들어 있지 않다. 「전 구간 최대 낙폭」은 상장 이래 최대가 **아니다** |

이 값들을 좋게 적지 않는다. 산출물의 「한계」 절이 매번 같은 내용을 싣는다.

## 하지 않은 것

- **자동 실행(워크플로)** — 기존 `macro-fetch.yml` 에 붙이면 커밋 사이클이 섞인다.
- **어드바이저 연동** — 의도적으로 하지 않았다. 이 프로그램의 존재 이유가 그것이다.
- **배당 반영 여부 확인** — 네트워크를 쓰지 않기로 했으므로 카드에 방법만 적어 뒀다.
- **다른 심볼 지원** — 입력이 QQQ 주간 종가 한 파일이다. 심볼이 늘면 그때 일반화한다.
